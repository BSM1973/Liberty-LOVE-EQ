# LOVE EQ 0.6 MOBILE TOUCH PRO
User test on iPhone 15 Pro: sound, preset loading, analyzer, stability and AUv3 discovery reported satisfactory; overview and touch targets too small. No DSP or parameter ID changes. New iOS-only compact view selected by available window size. Studio view remains available with original zoom/pan and advanced pages. Compact pages: EQ, DYN, MIX; band selection; graphic gain mode; real post spectrum and static nominal EQ response (not dynamic or full processing transfer function); vertical drag, FINE mode, double tap numeric tile reset. For very small host windows fall back to original zoomable view. Presets opens Studio browser; no replacement of existing preset system. Check on actual iPhone/iPad portrait, landscape, hosts and very small viewports; numeric tiles and graph nodes should be evaluated for touch accessibility. Build 3 intended for TestFlight. No real device validation yet.
