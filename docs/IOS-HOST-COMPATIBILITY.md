# LOVE EQ iOS v0.4 HOST COMPATIBILITY
## Device acceptance (all pending until a signed build is tested)
For Logic Pro for iPad, Cubasis 3, AUM, GarageBand and Loopy Pro record app version, OS, device, host AUv3 discovery, insert, bypass, UI resize, portrait/landscape, audio route change/interruption, automation, preset recall, project reopen, 30-minute playback, sidechain availability and 2/4/8 instances. Test 44.1/48 kHz and other rates only if the actual host/device supports them. Record screenshots and audio files. No claim of compatibility until observed. Relationship EQ is process-local; cross-process and cross-host exchange is not guaranteed. User presets may be sandboxed separately in the app and extension.
## Signing
Use the dedicated manual workflow named LIBERTY RELEASE CENTER - LOVE EQ iOS TestFlight. Configure a GitHub environment ios-distribution with secrets IOS_TEAM_ID, IOS_ASC_KEY_ID, IOS_ASC_ISSUER_ID, IOS_ASC_PRIVATE_KEY (raw .p8). Do not paste private keys into chat. Enable appropriate Apple team permissions and automatic signing; ensure the Apple Distribution identity/profiles are available or provisionable on the runner. Register the actual app and extension bundle IDs, create the App Store Connect record, provide an app icon, metadata and privacy information before submission. Verify Xcode SDK and archive scheme. Export first without upload; enable upload_testflight only on a deliberate run. Upload does not publish the application; TestFlight processing and beta review are separate. Existing desktop Release Center files are unchanged. This new workflow is in the LOVE EQ repo; central integration has not been verified.
## Evidence
Native processor QC adds parameter state round-trip and four prepare/release cycles at different sample rates, comparing two native instances. This is not iOS execution or a cross-platform null test. Bundle checks validate metadata, not host loading. UI and actual interruption recovery must be tested on hardware.
